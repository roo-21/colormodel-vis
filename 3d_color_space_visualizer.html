RGB Color Model
The RGB color model is an additive color space based on the Cartesian coordinate system. Red, Green, and Blue light beams are combined together in various proportions to produce a broad array of colors.
Geometric Axis Mapping:
  • X Axis: Red Component (0 to 255)
  • Y Axis: Green Component (0 to 255)
  • Z Axis: Blue Component (0 to 255)
Key Mathematical Equations:
C = (R, G, B) ∈ [0, 1]³
Grayscale Line: R = G = B (Main Diagonal)
Primary Applications:
Digital monitors, OLED displays, camera sensors, Web graphics, GPU framebuffers.
